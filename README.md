# Buku Tutorial Python Basic (Bab 2-10)

Materi ini dibuat untuk pemula (orang awam), dalam bahasa Indonesia, berbasis topik dari `pythonlearn.pdf`.

## Daftar Bab

- Bab 2: Variabel, Ekspresi, dan Statement
- Bab 3: Percabangan (Conditional Execution)
- Bab 4: Fungsi
- Bab 5: Perulangan (Iteration)
- Bab 6: String
- Bab 7: File
- Bab 8: List
- Bab 9: Dictionary
- Bab 10: Tuple

## Cara Pakai

1. Buka Jupyter Notebook / JupyterLab.
2. Masuk ke folder `buku_python_basic`.
3. Pelajari notebook berurutan dari `bab_02` sampai `bab_10`.
4. Jalankan setiap sel secara berurutan dari atas ke bawah.

## Catatan

- Beberapa contoh di Bab 7 membutuhkan file `contoh.txt` buatan sendiri.
- Silakan modifikasi contoh kode agar lebih paham.
